# Shared Types

Общие DTO и Zod-схемы между backend-сервисами и фронтом. Один source of truth — правь здесь, не дублируй интерфейсы в каждом сервисе руками.

## Конвенции

- Схема сначала в Zod (`z.object({...})`), TS-тип выводится через `z.infer<typeof Schema>` — не пиши отдельно `interface` и `Schema` вручную.
- Изменение схемы, которое ломает совместимость — обсуждай, где ещё используется, прежде чем менять.
- Не добавляй сюда бизнес-логику — только типы/схемы валидации.
