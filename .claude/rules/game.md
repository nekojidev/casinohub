# Game Service

Логика игр: рулетка → слоты → crash game, именно в этом порядке по возрастанию сложности.

## Конвенции

- Каждая игра — свой `GameEngine` (интерфейс: `validateBet`, `computeOutcome`, `calculatePayout`) — не смешивать логику разных игр в одном классе.
- Игра НЕ считает результат сама — результат приходит из RNG Service.
- Live-состояние раунда (особенно crash game) — в Redis, не в Postgres. Postgres — только архив завершённых раундов.
- Crash game: лок на весь раунд (`crash-round:{roundId}`), а не на пользователя — момент краша общий для всех игроков.
- Не начинай Crash game, пока Roulette и Slot не работают и не покрыты тестами — оставлена на шаг 13 корневого плана.

## Тесты

- RTP-тест на симуляциях (100k+ прогонов) для Slot — фактический RTP должен быть близко к теоретическому расчёту, посчитанному вручную в комментарии к тесту.
- Все ветки `isWinning` для Roulette (straight/red/black/even/odd/dozen).
