# API Gateway

Единая точка входа, GraphQL Federation. Начинать только когда минимум Wallet + RNG + Game (Roulette) готовы — раньше нечего федерировать.

## Конвенции

- Gateway не содержит бизнес-логики — только маршрутизация/агрегация схем и проверка авторизации на входе.
- Каждый сервис отдаёт свой кусок GraphQL-схемы (federation subgraph), Gateway их объединяет — не копировать типы вручную.
- JWT проверяется на Gateway один раз, дальше сервисам передаётся проверенный `userId`.
- Subscriptions (`crashMultiplierUpdated`, `balanceUpdated`) — отдельная транспортная логика, обсудить отдельно.

## Тесты

- E2E через Gateway, не через отдельные сервисы напрямую.
